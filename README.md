# OMy Grader
This Website is a landing page for our MCQ Grading System.
This Project aims to help teachers, Universities, and tutors do the correction of multiple choice questions, by the utilisation of Computer Vision.
# How can I use the OMy Grader?
You will find more information in the website about how to get and use our OMy Grader.
# Is this MCQ Corrector using Cloud Processing?
No, All data would be processed locally for safety and speed.
